# Stellar Classification ML

Machine learning project for classifying astronomical objects from the SDSS17 Stellar Classification Dataset into galaxies, stars, and quasars.

## Overview

This project compares supervised machine learning models for multiclass stellar object classification. The workflow covers data cleaning, feature preprocessing, model training, evaluation, hyperparameter tuning, and result comparison.

## Models Used

- Random Forest
- XGBoost
- LightGBM

## Techniques

- Exploratory data analysis
- Label encoding
- Outlier clipping
- Feature scaling
- Train/test splitting
- Confusion matrix analysis
- Classification reports
- Hyperparameter tuning
- Comparison with a public Kaggle notebook

## Files

- `stellar_classification.ipynb` - main notebook
- `stellar_classification_report.pdf` - project report
- `model_result_1.png`, `model_result_2.png`, `model_result_3.png` - supporting result images

## Dataset

The notebook expects the SDSS17 Stellar Classification dataset as `star_classification.csv`. The dataset is not included in this repository. Download it from Kaggle or another official dataset source, then place it beside the notebook or update the notebook path.
